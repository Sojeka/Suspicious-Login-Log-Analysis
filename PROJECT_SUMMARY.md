# Project Summary

## Problem
Suspicious authentication activity can be hidden inside large volumes of system logs.

## Solution
This capstone demonstrates a controlled workflow for collecting authentication events, monitoring network traffic, analysing logs, identifying suspicious patterns, and recommending defensive controls.

## Tools
VirtualBox, Kali Linux, Ubuntu Server, Wireshark and Python.
